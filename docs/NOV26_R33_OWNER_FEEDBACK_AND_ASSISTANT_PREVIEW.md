## Implemented offline assistant worker

`skell_sound_match.wav_only.assistant_preview` — independent deterministic candidate fitter and render gate. Explicit caller-confirmed same take and stage; file interface checks exact SHA256, matching rate, bounded geometry, does not infer identity or alignment. 5–60 seconds, max 1,920,000 frames; 32–192 kHz accepted, measured at 32 kHz synthetic / 44.1 kHz vocals. High-rate score calibration unverified. 9 shared-channel identity-anchored FIR variants and 6 linked dynamic variants (full-band / 3-band, bounded gain, causal 5/80ms detector and 12ms control smoothing). FIR normal equations accumulated in bounded batches. First 45% fit, middle 25% selection, last 30% evaluation. Compare against raw and train-gain-only, separate spectral, envelope, waveform, stereo and RMS gates; at least 5% composite improvement and estimated 4x peak <= -1 dBTP. Metric uses uncentered channel correlation (not the exact earlier centered Pearson implementation). Return NO_IMPROVEMENT or AUDITION_ONLY; never apply a preset. File API re-decodes PCM24 FLAC, rechecks exact export metrics/peak, rejects existing output directory; local reports and fitted coefficients private. 11 local tests passed, including a synthetic successful export and no-overwrite. No native DSP equivalence or realtime CPU claim.
